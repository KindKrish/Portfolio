# CS 360 Mobile Application Development Portfolio

## Event Tracking App

**1. Briefly summarize the requirements and goals of the app you developed. What user needs was this app designed to address?**

The goal of my Event Tracking App was to help users organize and manage their events in one place. The application was designed to make it easier for users to create, view, update, and delete events without having to remember everything themselves. The main focus was creating a simple and organized application that users could navigate without difficulty.

**2. What screens and features were necessary to support user needs and produce a user-centered UI for the app? How did your UI designs keep users in mind? Why were your designs successful?**

My application included screens for logging in, creating an account, viewing events, and adding or managing events. I focused on keeping the layout simple with clearly labeled buttons, consistent colors, and easy navigation. I wanted users to understand how to use the application without needing additional instructions. I believe the design was successful because it focused on the main functions rather than adding unnecessary features.

**3. How did you approach the process of coding your app? What techniques or strategies did you use? How could those techniques or strategies be applied in the future?**

I approached the coding process by working on one part of the application at a time. I started with the UI design and then worked on connecting the different screens and adding functionality using Java and Android Studio. Breaking the project into smaller tasks helped me understand the code and identify problems more easily. I plan to continue using this approach in future programming projects because it makes larger assignments more manageable.

**4. How did you test to ensure your code was functional? Why is this process important, and what did it reveal?**

During development, I used Android Studio to check my code, identify errors, and work through issues as I built the application. Testing is important because an application might look correct in the design editor but behave differently when it runs. This process helped me understand why developers need to check both the appearance and functionality of an application instead of assuming everything will work correctly.

**5. Consider the full app design and development process from initial planning to finalization. Where did you have to innovate to overcome a challenge?**

One of the challenges I experienced was understanding how to connect the UI screens with the actual application functionality. Designing the screens was easier than making the different components work together. I had to review my code, make adjustments, and find different ways to solve problems. This experience taught me to be patient and approach programming challenges one step at a time.

**6. In what specific component of your mobile app were you particularly successful in demonstrating your knowledge, skills, and experience?**

I believe I was particularly successful in designing the user interface and organizing the application's screens. I was able to apply what I learned about layouts, colors, buttons, and navigation to create a consistent design. Comparing my initial project design with the later development stages helped me see how much I had learned throughout the course. I am proud of the progress I made in understanding Android application development.
